# AAR v0.2 Wire Freeze — Build Rubric (Claude planning bookend)
2026-07-14. Input to the Codex 3-gate build under the edgeproof rc-gate
process. Sources of truth: `03-spec-v0.1.md` (v0.1.1, errata folded) +
`07-threat-model-v0.1.md` (R-15..R-38 stubs). This rubric decides what the
v0.2 freeze covers, what it explicitly defers, and the pass/fail bar.

## Objective
Freeze the normative wire for AAR v0.2: CDDL, canonical bytes, receipt-ID
calculation, signature inputs, validation order, reason codes, and externally
generated byte-pinned KATs — the artifacts whose absence made v0/v0.1 a
requirements draft (Codex spec-challenge finding 2). After this freeze,
profile assertions become testable and the reference Verifier has a target.

## Wire discipline (inherited, normative)
From edgeproof-sdr v1.1 by explicit import, not re-derivation: deterministic
CBOR (RFC 8949 §4.2 core requirements), closed schemas (no unknown keys),
COSE_Sign1 ES256, detached-payload rules, strict first-failure with
enumerated reason codes, KATs generated by an implementation-independent
harness and pinned as bytes.

## KAT bar (acceptance criteria — all pass/fail)
1. **Positive KATs**: ≥1 byte-pinned known-answer per node type, edge type,
   epoch transition, anchor proof, Merkle proof, and bundle — externally
   generated, committed as bytes.
2. **Negative fixtures**: one per reason code — no reason code ships without
   a fixture that triggers it and only it.
3. **Class-boundary KATs** (T-P2): for each evidence-class boundary
   (3 time × 5 outcome × 3 provenance transitions), an artifact set that
   satisfies the lower class and fails the higher — verifier must recompute
   "artifacts satisfy declared class" per the G4 rule.
4. **Adversarial graph fixtures** (R-29/T-G1): splice, dangling parent,
   duplicate identity, wrong-attempt authorization, cross-epoch replay,
   dominator violation — each MUST fail with its own code.
5. **Epoch/equivocation fixtures** (R-26/R-27): fork, ID reuse, rollback,
   two-manifests-one-epoch, late insertion — each MUST fail or verdict as
   specified.
6. **Determinism check**: two independent encoders (Codex impl + harness
   impl) produce identical bytes for every positive KAT input.
7. **v1-compat guard**: edgeproof-sdr v1 wire bytes remain byte-identical
   under any shared tooling (the v0.2 work must not disturb the shipped SDR
   family — same bar as the v0.2.0 receipt-family build).
